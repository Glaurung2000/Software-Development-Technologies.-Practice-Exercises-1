# Лаборатоные работы по предмету "Технологии разработки ПО"

**Версия:** 1.0

## Описание
Данный репозиторий содержит проект, созданный в рамках лабораторных работ по дисциплине "Технологии разработки программного обеспечения".

## CI/CD
Настроен пайплайн GitHub Actions, который автоматически проверяет текстовые файлы на наличие ошибок (пустые файлы) и собирает их в артефакт при каждом пуше в ветки `main`, `development` и `release`. Также настроены правила для защиты веток `Branch protection rules`.
